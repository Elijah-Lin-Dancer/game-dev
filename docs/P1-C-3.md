# P1-C-3：Title / Select / 设置 / 制作名单 / Map 难度覆盖层

状态：已完成并推送 `f34d355`（代码 / 构建）、`e8098fe`（本地验收文档）；Pages 已切到 `game.fe65475a.js`，线上 Title / 设置 / 名单 / 难度 / Select / Play 实测通过。线上验证记录随本页后续文档提交推送。

## 范围

- Title：标题、副标题、4 个主菜单、设置面板、制作名单迁移到 `tokens / primitives`。
- Select：3 张角色卡迁移到 `makeCard / makeText`，保留立绘、定位、HP / 攻 / 速 / 武器、技能、未解锁价格与全部选择逻辑。
- Map：`openDiff()` 难度覆盖层迁移到 `makePanel / makeCard / makeText`，保留三档难度、按章解锁、当前档与关闭行为。
- 只做视觉 / 布局 / 交互层迁移，不新增玩法，不改解锁、难度、导航和文案。

## 实现

### Title

- 标题 `归 途` 使用 `h1` 24px，`星 火 之 章` 与说明文案使用 12px；删除原 36 / 14 / 11px。
- 4 个主菜单改为 320×36 `makeCard` 行，含主文案 + 次级说明；选中有金框，右侧 `›`。
- 菜单行：开始冒险 / 进入世界地图；收藏小屋 / 武器、角色、图鉴；设置 / 静音、震屏；制作名单 / 素材与致谢。
- 设置面板为 300×190 `makePanel`，带全屏遮罩、面板 hit 阻挡层、2 张 260×32 `makeCard` 行；静音 / 震屏支持点击、↑↓ + Enter 切换，ESC 或点空白关闭。
- 制作名单为 420×230 `makePanel`，12px 正文 + ghost「关闭 ×」按钮；点按钮或遮罩关闭。
- 角色立绘缩到 1.0，位置 `S.H-58`，不再与菜单重叠。

### Select

- 3 张角色卡改为 128×232 `makeCard`，左侧绿色 / 锁定灰条；卡内保留立绘、名称、定位、HP / 攻 / 速 / 武器、技能名与描述、未解锁价格。
- 选中卡金框，立绘 1.6×；锁定卡立绘降透明，价格标记移到卡底 `y=208`，不再压住头像。
- 文字统一 12px；底部提示改 `caption`。
- 点击锁定卡只 toast；点击开放卡仍走 `patchSave({lastChar})` + `NAV.reset('play')` + `scene.start('play')`。

### Map 难度覆盖层

- 460×228 `makePanel` + 遮罩 + 面板透明 hit 阻挡层。
- 标题 24px，副标题 12px。
- 三档难度改为 412×34 `makeCard` 行，当前档金框，锁定档灰条，右侧状态「当前 / 已解锁 / 需通关普通 / 需通关噩梦」。
- 保留 `tierUnlocked / chooseDiff / closeDiff / NAV.openOverlay('difficulty')` 行为；点击空白遮罩、ESC、`back()` 均可关闭。

## 视觉门禁

- 字号只来自 `UI.size`：`h1=24`、`h2/body/caption=12`；本切片三个场景无散落 13 / 14 / 16 / 36px。
- 960×540 与 640×360 截图检查：Title 菜单不压立绘与底栏，设置 / 名单不裁切，Select 3 卡在 640 下文字不溢出，难度层三行与底部提示不重叠。
- 键盘：Title ↑↓ + Enter、设置 ↑↓ + Enter、Select ←→ + Enter / 空格、Map ↑↓ + Enter、难度层 ESC；均保留。
- 触控：Title 菜单行、设置行、名单关闭按钮、Select 卡、难度行、遮罩空白关闭均已实际点击验证。
- 非颜色状态：锁定卡保留「未解锁 · N 宝石」「需通关普通 / 噩梦」文本，不只靠灰条区分。
