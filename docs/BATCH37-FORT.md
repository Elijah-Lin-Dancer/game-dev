## 已修真实缺陷

1. **远程怪隔墙放弹幕**：`enemyShot()` 增加 `lineOfSight()` 采样，蜘蛛 / 骷髅 / 眼怪在墙后不再开火。
2. **远程怪刷进 1 格死角**：`findFreeSpot()` 按怪种要求 2–3 个开放邻格，避免刷在墙角单格、近战砍不到。
3. **旧堡首章密度**：旧堡小怪统一封顶 3 只；首间 2 只；无精英的开局模板。
4. **旧堡没有补给房**：`roomTemplate` 改为 `battle / battle / rest / battle / gate / boss`，把精英房从第二章开局移除，休息房固定在第 3 间。
5. **机关房守卫 3→2**：机关房是解谜房，3 个守卫会把进 Boss 前的血线压到 5 以下；最新一次以 18 血进 Boss。
6. **基础怪伤害 3→2**：幼虫 / 史莱姆 / 鼹鼠；第二章 20 血忍者从“7 次碰撞死”回到 10 次。
7. **Boss 掉落结算**：Boss 死后 1.2s 结算，并在 `win()` 前自动收取剩余金币 / 心 / 强化 / 钥匙。
