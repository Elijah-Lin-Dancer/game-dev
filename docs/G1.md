### 单屏与世界坐标

- 单屏 `480×272`，6 屏共 `2880×272`；`WORLD_Y = Math.round((S.H - 272) / 2)`，640×360 下为 44，960×540 下为 134。
- 每屏数据坐标以屏内左上角为 `0,0`；玩家脚点是碰撞与层级判定基准。
- 镜头仍按 `S.W / S.H` 跟随，960 视口会同时看到相邻屏的约两屏宽，640 视口约 1.33 屏；这是“不黑场”的连续世界表现，不是六张独立截图。

## 2. 玩法与操作

- 移动：`WASD` / 方向键；触屏点空白处朝目标走。`SPEED=78`；小雨 ×1.05，雾 ×0.92，洞穴内再 ×0.9。
- 交互：`E` 采集 / 交谈；`SPACE / J` 斩击；`R` 失败重试；`ESC` 关面板 / 回小屋。
- 采集：11 丛草药，靠近 `E`，2 秒读条，得 2 株；移动打断；90 秒重生。
- 委托：村医阿杏「草药五株」；首次交谈接受，集满 5 株再交谈弹「交付 5 株 / 再等等」；交付扣 5 株、`tokens +1`。
- 战斗：玩家 `HP 20`、受击 `IFRAME 700ms`；斩击 `CD 320ms / RANGE 62 / DMG 3`；第六屏 `苔背巨兽` `HP 56 / DMG 4 / 奖励 3 碎片`，有追逐、爪击前摇、扑击前摇 + 跳扑、回收状态；击杀写 `boss='done'`、`tokens+3`，弹「草原的星火 · 已归位」；玩家死亡弹「星火熄灭」，`R` 重试 / `ESC` 回小屋。
- 天气：`rain` 雨粒子 + 移速 1.05；`clear` 晴；`fog` 慢雾粒子 + 雾幕 + 暗角 0.48。洞穴内叠 `caveShade 0.46`。
- 地形：`surface / plateau / cave`；台地矩形抬高、顶部亮边、底部阴影、左右 cliff、底部坡道缺口；洞穴暗色地面 + 四周边框 + 顶部 48px 入口；从玩家脚点落层实时更新 HUD「· 台地 / · 地穴」。
- 存档：`na.world v2`；刷新保留到过屏、草药、委托、Boss 是否已杀、碎片；坐标 / HP / 战斗态不进档。

### 3.1 帧率说明

- 本机无头 Chromium 的 **原始 `requestAnimationFrame` 实测约 29–31 Hz**；同一页 `game.loop.actualFps` 在 960×540 约 46 → 30、640×360 约 45 → 30，和 raw rAF 同步下降，说明是运行环境的刷新上限，不是 G1 场景掉帧。
- 因此 G1-9 只记录“世界逻辑在 30 Hz 环境下持续运行、无错误”；不把 30 Hz 当作 60 Hz 达标。交互浏览器（有 GPU / 正常刷新）需复测 60 Hz 目标，见 §5。

## 5. G1 明确边界 / 已知限制

- 台地与洞穴目前仍是清晰的**功能矩形**，边缘只做了亮边 / 阴影 / cliff / 洞口贴图，未做不规则地形拼贴；视觉上仍偏“块状”。
- `field-4` 名「断桥」但还没有真正的桥体 / 沟壑几何，只是草原雨屏；桥体留 G2 或后续打磨。
- `field-3` 洞穴高度压到 76px，目的是在底部留出可通行的草原走廊；从上方 48px 开口进出，不是完整地下迷宫。
- 960×540 视口会同时看到相邻屏约两屏宽的内容；这是连续世界镜头，不是六张独立屏。跨屏截图需等相机约 0.45s 收敛，否则会拍到上一屏残影。
- 无头 Chromium 只有约 30 Hz；正常有头 / GPU 浏览器的 60 Hz 仍需人工复测。G1 未做移动端 / 触屏真机验收。
- Boss 的可复现击杀验收把 Boss 停在 `distBoss=16` 并冻结 AI，只验证伤害累积、死亡、奖励与面板；真实 AI 爪击 / 扑击伤害已单独用玩家 `HP 20→16→8→0` 实测，但没有录下完整 56 HP 的完整走位战。
- `worldSave` 不存坐标 / 天气 / 血量；刷新从 `field-1` 首屏重进。
- Pages 线上验收在推送后独立记录；当前 G1 文档的本地验收以 2026-11-23 的构建 `game.0fa069a3.js` 为准。
