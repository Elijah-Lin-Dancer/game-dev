## 组件约束

- 卡片和按钮的视觉放进 `container`，输入交给独立顶层 hit 层，避免嵌套 Container 命中不稳定。
- 卡片只负责底色、左侧类型色条、悬停 / 选中 / 锁定描边；内容由场景注入，不读写存档。
- Hall 购买按钮保留原逻辑：`buy('weapon'/'char')` 读存档、扣宝石、解锁后重绘。
- Map 节点只负责选中与 toast；真正进入 Select 仍走 `NAV.push('select')`。
