# 《归途：星火之章》· UI 改造高保真原型稿

> 视觉落地单元 K：用真实素材把改造后的五个界面渲染成可交互、可离线打开的单文件 HTML。
> 基线：`game-repo` commit `f8d4a22`；逻辑分辨率 640×360，2× 显示 1280×720；本稿不改动 `game-repo` 任何文件。

## 一、如何打开

- 双击 `ninja-revamp-mockup.html` 即可在浏览器打开；**离线可用**，不依赖服务器、CDN 或联网请求。
- 操作：`↑↓←→` 移动焦点 · `Enter` 确认 · `ESC` / 鼠标右键原路返回；鼠标可直接点选卡片与按钮。
- 页脚常驻当前返回栈深度（`depth 0 根目录` / `depth 1` / `depth 2`）。
- 说明：稿内星数、解锁状态、宝石数为**示意值**；章名、关数、房间数、怪物、Boss、武器数值、角色技能与初始武器均读取真实数据（`chapters.json` / `weapons.json` / `chars.json`）。

## 三、素材来源与授权

- **美术**：Ninja Adventure（CC0），原包 `assets/01-primary/NinjaAdventure/`。
  - 武器图标、角色脸、怪物 / Boss 头像切片：取自游戏图集 `web/atlas/core.png`，坐标按 `web/atlas/core.json` 裁切。
  - UI 套件：按钮四态、九宫格面板、凹槽底图、焦点环、DialogBox / ChoiceBox / FacesetBox，取自 `Ui/Theme/Theme1/` 与 `Ui/Dialog/`。
- **字体**：`web/fonts/game.woff2`（Fusion Pixel 12px 子集，OFL），已以 base64 内嵌。
- 全部图片与字体均为 base64 data URI 内嵌；HTML 内无任何 `http/https` 外部引用、无 CDN 依赖。

## 四、改造前 → 改造后对照要点

1. **导航不再有死胡同**：每页左上「← 返回」，ESC / 右键 / 返回按钮三通路等价原路返回；制作名单、设置是可独立关闭的覆盖层，关闭后回到发起方焦点。对照现状：名单页、小屋页没有返回入口（问题 #1、#2、#5）。
2. **主流程直达选关**：标题 → 章节地图 → 章内关卡 → 选人；武器 / 角色 / 图鉴降为地图二级「归途小屋」，不再挡在开打主路上（问题 #4）。
3. **页面从纯色矩形升级为分层 UI**：字号 24 / 16 / 12 / 10 / 8 阶梯；图标进凹槽底板；稀有度双编码（边框色 + 色点）；选中态金框 + 填充提亮 + 金色辉光 + 上移 2px；关卡节点按形状区分类型，不再只靠红字（问题 #7、#8、#9、#10）。

## 六、自检口径（已通过）

- 无外部请求、无 404、控制台无报错；五个界面均可到达。
- 返回栈：`stages → ESC → map → ESC → title`；设置覆盖层 ESC 可关闭；根目录 ESC 为空操作。
- 内容约束：复用现有 3 角色 / 6 武器；灰色占位卡仅预览未来扩展位（武器 4 个、角色 3 个），本稿不承诺新美术内容。
