# G0：开放世界雏形「远征」

日期：2026-11-23  
范围：`docs/OPENWORLD.md` §6 的 G0，独立模式第一段。  
结论：3 屏连通、2 种气候、3 丛草药 + 村医 + 1 条采 5 草药委托、独立 `na.world`、小屋东门入口与 W1–W5 全部跑通。

## 2. 玩法与操作

- 移动：`WASD` / 方向键；触屏点空白处朝目标走。
- 交互：`E` 采集 / 交谈；`ESC` 关对话 / 关委托面板 / 回小屋。
- 草药：草原 3 丛；靠近按 `E`，2 秒读条，得 2 株；移动会打断；采完 90 秒重生。
- 委托：首次与村医阿杏交谈接受「草药五株」；集满 5 株后再交谈，弹出「交付 / 再等等」；交付扣 5 株并记 `tokens +1`。
- 气候：草原小雨（雨粒子，移速 +5%）；竹林晴；沙漠沙尘（沙粒 + 暖色遮罩 + 暗角 0.62）。
- 存档：刷新后保留到过哪屏、草药数、委托状态；不修改主线 `na.save`。

## 5. G0 明确边界

- 单屏采用现有逻辑分辨率 640×360（3×640=1920 世界像素），没有按 `OPENWORLD.md` 的 30×17 格 / 480×272 做小屏拼块；`G1` 铺 6 屏群系时再切 30×17 模板。
- 镜头是跟随式缓动（0.1/帧，约 0.45 s 收敛到目标），不是独立的「距边缘 1.5 格触发 + 固定 Tween」状态机；验收只要求不黑场，G1 再补边缘触发和相邻屏预取。
- 竹林天气字段为 `clear`，只做了晴；雾留给 G1。
- 没有世界敌人、宝箱、篝火、世界 Boss；只有草、村医、委托。
- `na.world` 不存坐标、不存采集读条、不存天气；刷新从草原首屏重进。
- 入口门槛是竹林村 5 个主线关均至少 1 星，不是「任意一关通关」。
- 调试直达 `?world=1&debug=1`，`window.__world` 仅在 `debug` 下暴露。
