# MASTERPLAN：从原型到"大作"的骨架

> 2026-11-21 定稿。批 1–8 解决的是"能不能打"，这份文档解决"像不像一款完整的游戏"。
> 对标坐标：**元气骑士**（关卡与大厅结构）、**泰拉瑞亚**（Boss 顺序驱动的进度感）、**Minecraft**（用进度/成就当引导）。
> 原则不变：**素材优先**——能拿现成件就不画（ADR 0013 四级顺序）；宁可少一个系统，不做假功能。

## 1. 现在缺的是什么（诚实盘点）

| 维度 | 元气骑士 | 本作现状 | 差距 |
|---|---|---|---|
| 入口 | 骑士之家大厅（角色/工坊/花园/地窖/NPC） | 标题 → 大厅三页签（武器/角色/图鉴） | 只有"看"，没有"做"：无锻造、无训练、无 NPC |
| 关卡 | 3 大关 × 5 小关 = 15 关 + 隐藏 | 单局 5 房随机，通关即结算 | 没有"关"的概念，也没有跨关进度 |
| 地图 | 每关场景主题固定、房间布局随机 | 无地图界面 | 玩家不知道自己在哪、下一步去哪 |
| 故事 | 弱叙事，靠 NPC 和赛季 | 只有引路人几句台词 | 没有主线动机，也没有结局 |
| 元进度 | 宝石解锁角色/技能/武器、花园种植 | 宝石解锁武器/角色 + 图鉴 | 缺"长期目标"，通关一次就没动力 |
| 设置 | 音效/音乐/语言/操作 | 静音/震屏/难度 | 够用，但缺"重开本局""返回标题"这类导航 |

结论：**本作不缺战斗手感，缺的是"容器"**——把已有的 12 关素材、10 种怪、2 只 Boss、14 张天赋装进一个有地图、有章节、有叙事的框架里。

## 2. 结构设计（照元气骑士的骨架，用泰拉瑞亚的 Boss 节奏）

### 2.1 世界地图

三章，每章 4 关 + 1 隐藏关，共 12 关主线：

| 章 | 主题 | 现成素材 | 关底 Boss（包内 12 只轮换） |
|---|---|---|---|
| 一 · 竹林村 | `TilesetField` + `TilesetHouse` + `VillageAbandoned` | 已用（批 6 field 皮肤） | GiantFrog（青蛙）、GiantRacoon（浣熊） |
| 二 · 旧堡 | `TilesetDungeon` + `Interior` + `Pipes` | 已用（批 6 dungeon 皮肤） | GiantBlueSamurai（蓝武士）、GiantRedSamurai（赤武士） |
| 三 · 沙海遗迹 | `TilesetDesert` + `TilesetWater` + `Element` | **未接**，图集切片待做 | TenguBlue / TenguRed（天狗）、GiantSpirit（精怪） |

隐藏关「无光回廊」：三章全三星后解锁，`cycle ≥ 2` 难度、双 Boss 同场。

地图界面（场景 `map`）：一章一页，关节点连线，节点状态 = 未解锁 / 可进入 / 已通关（★×3）。星级判据：

- ★1 通关
- ★2 通关且剩余血 ≥ 70%
- ★3 通关且未使用回血房

### 2.2 关卡内部

沿用现有 `dungeon.js` 编排，加一层"关"的包装：

- 一关 = 4 房 + 1 Boss 房（Boss 房固定结尾），房型池按章节主题裁剪（竹林多草地/商店，旧堡多宝箱/精英，沙海多陷阱/毒雾）。
- 关内进度存进本局状态：`{ chapter, stage, roomsCleared }`，过 Boss 后进"结算 → 世界地图"，而不是直接重开。
- 关卡难度 = 章节系数 × 关卡序号 × 周目系数；Boss 池按章节取，不跨章乱入。

### 2.3 大厅：从三页签扩成「归途小屋」

保留现有三页签作为「图鉴室」，新增三个功能区（同一场景，横向切换，像元气骑士那样能在大厅里走动也可以后做）：

| 区 | 能做什么 | 依赖 |
|---|---|---|
| 出发台 | 选章节 / 看地图 / 进关 | 世界地图数据 |
| 锻造坊 | 用金币把武器升 1–3 级（伤害/攻速），宝石镶嵌词条 | 现有 6 武器 + 掉落池 |
| 训练场 | 打木桩看 DPS，试武器手感 | 复用 `attack()`，木桩是 `props` |
| 图鉴室 | 现有武器/角色/图鉴三页签 | 已有 |

NPC：商人（卖一次性道具）、铁匠（锻造）、引路人（讲故事/给任务）。NPC 用包内 `villager`/`villager2` 立绘 + 对话框，不新画。

### 2.4 主线故事

一句话动机已经写在标题里："夺回被抢走的魔法石"。扩展成三章三段：

1. **竹林村**：村子被抢，引路人带你追到旧堡门口；发现魔法石被拆成三块。
2. **旧堡**：赤武士守着第二块；他是被魔法石控制的，打赢后给一块 + 一句反转。
3. **沙海遗迹**：天狗把最后一块献给了"地底的东西"；打赢进隐藏关，收尾。

叙事载体：关卡首尾各一段对话框（现有 `showPanel` + 引路人贴图），章节间插一张"过场卡"（图 + 三行字，不写长文）。**不做全程配音、不做分支**——成本高、收益低。

### 2.5 元进度（长期目标）

- **宝石**：解锁武器/角色（已有）→ 追加解锁"第二技能"（元气骑士式，每角色 1 个额外主动技）。
- **星级**：12 关 × 3 星 = 36 星，累计解锁隐藏关与皮肤。
- **成就**：第一版 12 条（首通/无伤/单局 5 杀连击/全武器试过…），达成弹一条 toast，写进存档 `na.save.ach`。
- **周目**：通关后 `cycle + 1`，敌人血量/伤害乘区、房型池加难，已有 `CFG.cycle` 可直接接。

## 3. 分期与验收

| 阶段 | 内容 | 验收（可截图/可测） |
|---|---|---|
| **A（批 9）** | 章节数据 + 世界地图场景 + 关卡包装（4 房 + Boss、结算回地图） | 地图能进三章；进关后第 5 房必为 Boss；打完回地图并亮星 |
| **B（批 10）** | 沙海遗迹素材接入（Desert/Water/Element 切片）+ 6 只新 Boss 编排 + 星级判据 | 三章皮肤各不相同；每章 Boss 按池抽取；★2/★3 判据能复现 |
| **C（批 11）** | 小屋扩建：出发台/锻造坊/训练场 + 3 个 NPC | 锻造能把武器升级并落盘；训练场 DPS 可读；NPC 对话框可交互 |
| **D（批 12）** | 主线演出：章节过场卡 + 引路人 6 段对话 + 结局 | 三章首尾对话齐；结局有"魔法石归位"结算 |
| **E（批 13）** | 成就 12 条 + 第二技能解锁 + 无尽模式（可选） | 成就 toast 与存档；第二技能可用且单独计费 |
| **F（批 14）** | 工程化：PWA、移动端摇杆、首屏预算、冒烟脚本 | 手机可玩；首屏 < 2 MB（不含音乐） |

排序理由：A 是骨架（没有它，B–E 都是散的）；B 解决"三章看起来一样"；C/D 是最像"大作"的部分；E/F 属于锦上添花，等前四阶段稳了再说。

## 4. 素材账（哪些要新找、哪些包内够）

| 需求 | 包内 | 结论 |
|---|---|---|
| 沙漠章节地面/墙 | `TilesetDesert.png` 已有 | ✅ 切片即可，零外部 |
| 水火元素/机关 | `TilesetElement.png`、`TilesetWater.png` | ✅ 够做熔岩池、水沟 |
| 6 只新 Boss | `Actor/Boss/` 剩 GiantRedSamurai / TenguBlue / TenguRed / DemonCyclop / GiantFlam / GiantSpirit | ✅ 够三章轮换 |
| 新怪（沙海） | `Actor/Monsters/` 剩 Reptile / Snake / Fish / Octopus / Kappa / Lantern / Dragon / Demon | ✅ 挑 6 只接入，需逐个校 anchor |
| 地图界面图标 | `TilesetElement`/`TilesetHouse` 里有路标、门、旗帜 | ✅ 不新画 |
| 章节过场卡背景 | 用现有 tileset 拼一张 + 引路人立绘 | ✅ 拼贴，不自绘 |
| 大厅地面（可走动版） | `Interior` 花砖已有 | ✅ |

结论：**A→E 全程预期外部素材 0、自绘 0**，只有"沙海怪 anchor 校准"这类体力活。

## 5. 不做清单（明确砍掉，避免无限膨胀）

- 不做开放世界、不做程序化地形生成（Terraria 那套与本作 5 房一局的节奏冲突）。
- 不做多人联机、不做 UGC 关卡编辑器。
- 不做赛季/战斗通行证（元气骑士的赛季是长线运营，单人项目不做）。
- 不做全程配音、不做分支剧情。
