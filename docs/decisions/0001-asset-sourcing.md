# 0001 素材来源与授权策略

- 状态：已定稿
- 时间：2026-11-19
- 涉及段：1 调研

## 背景

新游戏准备阶段需要先定素材来源。素材直接决定美术风格上限与授权风险，而小游戏上线要过审核，授权必须先于素材质量判定。

## 决策

1. **主来源只取绿档**（CC0 / MIT / OFL / 免版税），黄档（CC BY）只用于图标，并预留游戏内鸣谢页。
2. **排除 LPC 全套**（CC-BY-SA 3.0 / GPL 混合）。内容质量高，但衍生美术须同协议开放，不适用于商业项目；仅作学习参考。
3. **不采用「多包各取一半」的拼装方式**。先定一个主美术包，其余只做填空。理由：风格打架的代价远高于素材成本。
4. **每个素材入库同时存包内 LICENSE 原文**，登记到 `assets/CREDITS.md`。
5. **代码级特效走 pixelfx**（MIT），不引入第三方依赖；手机端优先导出序列帧，实时 JS 只留给少量招牌特效。

## 备选方案与否掉理由

| 方案 | 否掉原因 |
|---|---|
| 以 LPC 为主美术库 | CC-BY-SA 传染，商业项目不适用 |
| 全部购买商用素材包 | 现阶段玩法未定，采购先于需求会浪费预算 |
| 纯 AI 生成美术 | 风格一致性不可控，且难以跨版本迭代 |

## 什么情况下改推荐

- 玩法确定为 3D 时：本清单的 2D 部分作废，改走 Quaternius / KayKit（CC0）。
- 需要中文像素字体的高字重版本时：改用 Fusion Pixel 的粗体分支。
- 上线区域要求署名页不可行时：把 CC BY 档的图标替换为 CC0 作者的作品（game-icons 内有部分 CC0 作者）。
