# ADR 0010 · 内容扩充：敌人脾气、Boss 二阶段、局内强化

日期：2026-11-20
状态：已采纳

## 背景

工程线走完后，玩法内容还是"一只追人怪 + 一个只会冲的 Boss"。素材包里躺着 58 种怪物、12 个 Boss，不用起来等于白拿。玩家在第 3 间房就能看完所有套路，没有"这局和上局不一样"的感觉。

## 决定

### 1. 四种小怪，各自有脾气（不是换皮）

| 怪 | 行为 | 威胁方式 | 破法 |
|---|---|---|---|
| Beast | 直线追击，卡住侧滑 | 贴身 | 边退边砍 |
| Cyclope（独眼） | 走近 → 蓄力 400ms（橙身抖动）→ 230px/s 冲刺 260ms → 瘫 1.4s | 冲刺抢身位 | 看到变色就侧移，趁冲刺后摇打 |
| Eye（眼怪） | 保持 110–230px，每 1.6s 吐一颗能量球（150px/s，2 血） | 远程消耗 | 贴脸逼它后退，或贴身打断 |
| Larva（幼虫） | 更快追击（56），死亡分裂 2 只小幼虫（各 3 血、更快） | 数量压制 | 先清小只，别在幼虫堆里停手 |

房间的怪按房间序号配比：第 1 间纯 Beast 当教学，第 2 间起混 Cyclope，第 3 间起混 Eye，第 4 间起 Larva。这样"越往里越难"不是靠堆数量，而是靠新行为。

### 2. Boss 二阶段（半血变脸）

- 血量 ≤ 50%：进入 `roar` 0.65s（震屏、变红、无敌、血条转橙），随后 `phase2 = true`，移速 ×1.3、蓄力时间 ×0.75。
- 招式从"只有冲撞"变成"冲撞 + 砸地"：每三次出手，第三次改成砸地——先在玩家脚下画一个 78px 预警圈（0.52s），然后跳过去（0.46s 抛物线）落地，圈内吃 4 血并被推开。
- 一眼能读：红身抖动=冲撞，黄色圈=砸地。两种预警的时间窗不同，玩家有空间换位。

### 3. 局内强化（三张卷轴）

清房有 35% 概率掉一张，Boss 必掉一张。三种效果都是"叠层线性"：

| 卷轴 | 效果 | 叠两层后实测 |
|---|---|---|
| ScrollFire 攻 | 伤害 +1/层 | 3 → 5 |
| ScrollPlant 速 | 移速 +12%/层 | 96 → 119 |
| ScrollIce 频 | 攻击间隔 −15%/层（保底 0.4 倍） | 300ms → 255ms |

拾取有飘字，HUD 右上角显示 `攻+N 速+N 频+N`，不吃强化就不显示。

### 4. 数值全部可调

新增的四组参数（`cyclope` / `eye` / `larva` / `upgrades` / `boss2`）都进了 `web/data/balance.json`，`data.js` 用"只覆盖默认里已有的数字字段"的深合并，改 JSON 刷新即生效。

## 实测（无头 Chromium 逐帧采样）

| 项 | 结果 |
|---|---|
| 眼怪 | 弹数在 0/1 之间循环；子弹命中扣 2 血（20→18→16）；打墙即销毁 |
| 独眼 | 阶段轨迹 `walk → windup(400ms) → dash`：y 由 301 冲到 347（≈230px/s），随后瘫 1.4s 再追 |
| 幼虫分裂 | 9 血挨第三刀 → 场上由 1 只变 2 只（各 3 血，位置 ±18px） |
| Boss 二阶段 | `roar → approach(phase2)`；招式序列 `lunge → lunge → slam → lunge → lunge → slam` |
| 砸地预警 | 截图可见 78px 橙色圈落在玩家脚下，Boss 黄身、血条转橙 |
| 强化叠层 | power2/speed2/atk1 → 伤害 5、间隔 255ms、移速 119 |
| 混编房间 | 第 4 间实测 `beast×3 + eye×2`；第 3 间 `beast×4 + cyclope + eye` |

## 修掉的三个坑（都是自测抓出来的）

1. `updateCyclope` 漏了 `e.phaseT -= dt` → 独眼永远卡在蓄力，一站就是十几秒。
2. Boss 半血判定写在 updateBoss 开头且没排除 `roar`，导致 roar 每帧重入、永远出不来。
3. `UPG_ICON` 只写进了使用处没写定义（批量替换锚点没落盘）→ 掉强化道具瞬间抛异常；直到 Boss 房掉落才暴露。

## 代价与边界

- 四种怪共用一张 4×4 的 16px 表，只有行走动画；没有攻击/受击专属帧，冲刺和蓄力靠染色+缩放表达，观感比"有独立动作帧"弱一档。
- 砸地是"瞬移+抛物线"，不做真正的碰撞体位移，也不会被墙挡住——房间够大时看不出问题，小房间可能穿墙落地。
- 强化只有线性叠层，没有稀有度、没有负面代价，后期容易滚雪球；等有"精英怪/词缀"再一起做取舍。
- 敌方弹幕只有一种直线球，没有散射、追踪。
