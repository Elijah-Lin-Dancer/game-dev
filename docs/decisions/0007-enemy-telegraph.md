# ADR 0007 · 敌人预警、绕障与镜头前瞻

日期：2026-11-19
状态：已采纳

## 背景

P2 通关后，Boss 与小怪的行为只有"沿直线朝玩家挪过去"，玩家被贴脸掉血时看不到任何前摇，读不出"该躲"，主观感受是"敌人不讲理"；镜头又死跟人物中心，转身时画面没有方向感。三处合起来正是"能玩但不像成品"的典型来源。

## 决定

1. **Boss 改状态机，伤害与动作绑定**
   `approach / windup / lunge / recover` 四态，蓄力 420ms（红身染色 + 1.6 倍放大 + 抖动 + 低频提示音），冲撞 220ms、速度 190px/s、沿锁定方向直走，缓 380ms。接触伤害只在 `lunge` 帧生效。

2. **小怪保留直线追击，加"卡住就侧滑"**
   位移低于预期 40% 累计 260ms → 顺垂直方向滑 420ms 后继续追。用假想位移而非真实寻路，零成本也能消掉"顶着墙角原地抖"的观感 bug。

3. **镜头跟随变慢 + 朝向前瞻**
   `camLerp 0.12`、前瞻 22px（纵向 0.8 倍），用 `1 - 0.004^(dt/1000)` 指数平滑，转身时视野自己先偏过去。

4. **参数全部进 `CFG`**，改手感只动数字，不动逻辑。

## 代价与边界

- Boss 只有一招冲撞，重复出现在 3 轮内就能被背下 → 后续需要第二招或二阶段，否则打熟了会腻。
- 侧滑是"假绕障"，遇到凹形墙可能来回滑、看起来像抽搐；真要做寻路得引入网格 A*，那是内容量起来之后的事。
- 镜头前瞻会让房间边缘的 `scrollX` 顶到边界，前瞻在边缘失效——这是可接受的，因为边缘本来就没有前方内容。

## 验证

见 `docs/PLAYTEST-3.md`：阶段序列实测 3 轮、蓄力期贴脸 0 伤害、冲撞 −3 单次结算、镜头前瞻实测 ±17px、提示条两种视口不裁。
