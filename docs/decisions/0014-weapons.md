# ADR 0014 · 批 1：武器系统（6 把、三系、掉落换装）

日期：2026-11-20
状态：已采纳（`web/data/weapons.json` + `src/systems/weapons.js`）

## 背景

到表现力线为止，玩家只有**一个动词**：挥砍。所有武器、所有战斗节奏都由 `CFG.playerDmg / atkCd` 两个数决定，打击感再好也只是一把刀在挥。批 1 的目标是让"拿到什么"变成决策——这是 roguelike 与"动作游戏"的分水岭（`docs/ROADMAP.md §2` 的 D1）。

素材关先跑完（`docs/BATCH1-ASSETS.md`）：6 把武器本体全在本包，`FX/SlashFx/` 还有 7 套 32×32 斩击帧。所以这批**没有外部素材、没有自绘**，只有接线与调参。

## 决策

1. **武器是数据，不是代码分支**。`web/data/weapons.json` 描述每把武器；`src/systems/weapons.js` 做字段归一化（类型不对就退回内置默认值）。`play.js` 里没有任何 `if (id === 'hammer')`——三系差异全靠 `kind` 与数值。
2. **只分三类，不细分**：`melee`（矩形判定 + 斩击帧）、`ranged`（飞行弹体）、`throw`（飞行弹体 + 穿透）。够表达六把武器的差异，又不至于为每把武器写一套子系统。
3. **伤害乘区分离**：`wdmg = CFG.playerDmg × weapon.dmgMul + powerStep × upg.power`。武器倍率是乘区 1，力量强化是乘区 2，互不污染（与 `ROADMAP §7` 的数值纪律一致）。
4. **冷却也按武器走**：`wcd = max(w.cd × minAtkMul, w.cd × (1 - atkStep × upg.atk))`。攻速强化对所有武器生效，但每把武器有自己的基准节奏。
5. **换装靠掉落，不做背包**。走过武器就换上，旧武器掉在脚下（`swapKeepOld`，可关），取回即换回。这样"换武器"永远是一次位置决策，不是菜单操作。
6. **斩击表现必须一一对应**：刀 `Slash`、巨剑 `SlashDoubleCurved`、锤 `CircularSlash`、杖 `SlashCurved`。同一个特效换颜色等于没做（W-2 判据）。

## 实现要点（踩过的坑，后面会再遇到）

1. **斩击帧的挂点比帧本身更重要**。第一次实现把 32×32 的斩击帧挂在 `player + 朝向 × 18`，缩放 2.9；结果弧线离人物 60 多像素，看起来是"特效自己在旁边播"。改成**挂人物身上、只前偏 12px**、缩放降到 1.9–2.5，才读得出"是这把武器挥出来的"。
2. **手持帧不能常驻**。素材里每把武器只有一个"举着"的静态姿势，常驻挂在手边像肩上插了把剑。改成**只在出手后 260ms 内显示**，配合旋转补间，反而更像挥砍。
3. **换装掉落要上锁**。旧武器掉在脚下时，如果不给 700ms 的 `lock`，下一帧就会被自己捡回去，形成"换装循环"。
4. **玩家弹体和敌人弹体必须分表**。`this.shots` 是敌人子弹（命中玩家），`this.bolts` 是玩家子弹（命中敌人）。合表会互相误伤，也会让 `updateShots` 的命中判定写成一团。
5. **调试口 `atkHold(ms)`**：本机无 GPU，1280×720 下帧率很不稳，`sleep(120)` 抓到的往往是"特效已经播完"的一帧。`atkHold` 让场景在**游戏时间**的 ms 毫秒处暂停，截图才稳定可复现。

## 影响

- `balance.json` 继续管角色与敌人；武器数值另立 `weapons.json`，两者不互相覆盖。
- 批 4（敌人）可以复用 `damageFoe` 与弹体表；批 5（多角色）只需要把 `startWeapon` 换成角色默认武器。
- 已知限制：**弓没有手持帧**（用图标顶）；角色没有"投掷"专用帧（用 Attack 帧 + 弹体）；近战斜向挥击只有 4 方向，斜 45° 靠旋转近似。
