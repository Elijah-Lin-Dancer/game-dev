- 上游：[0003 跨端与栈](0003-cross-platform-stack.md)

## 数值表（`web/main.js` 内 `CFG`）

| 项 | 值 | 为什么是这个数 |
|---|---|---|
| 心数 / HP | 5 颗 × 4 档 = 20 | `heart.png` 正好 5 帧（空、1/4、半、3/4、满），用现成美术 |
| 挨一下 | −3（掉 3/4 颗） | 6 下才死，够新手犯错，又不至于无压力 |
| 一刀伤害 | 3 | 怪 6 血 → 两刀一只，节奏快 |
| 怪血量 | 6 | 同上 |
| 攻击冷却 | 300 ms | 连按有节奏，不能无脑刷 |
| 命中冻结 | 55 ms | 打击感的来源。短于 40 感觉不到，长于 80 像卡顿 |
| 无敌时间 | 700 ms | 防止贴脸连咬致死 |
| 攻击判定 | 前方 30 px，框 34×30 | 比贴图宽一点，避免"看着砍到了却没掉血" |
| 怪速度 | 46（玩家 96） | 追得上但不能围死玩家，留出走位空间 |
| 同屏上限 | 4 只 | 超过 4 只在 360 高的视野里会变成一堵墙 |
| 补怪间隔 | 2.2 s | 清完场有空隙喘气，不空场太久 |

## 手感清单（每项都是刻意的）

| 效果 | 参数 | 意图 |
|---|---|---|
| 挥砍前冲 | 4 px 位移 + 90 ms 回弹 | 让动作有"发力"的方向感 |
| 身体挤压 | scaleX 2.3 / scaleY 1.75 干 70 ms | 卡通夸张，让挥砍有重量 |
| 相对速度杀 | 命中时玩家移速降到 65% | 攻击有代价，不能边跑边砍 |
| 命中冻结 | 55 ms 停推进 | 打击顿感，最关键的一味 |
| 震屏 | 0.006 / 80 ms（命中）0.012 / 180 ms（受伤） | 受伤的震感更强，区分"我打人"和"我被打" |
| 击退 | 怪 120，玩家 150，二次衰减 | 让接触有物理感，同时给玩家脱身空间 |
| 命中火花 | 白圆 7 px → 2.4 倍 160 ms | 命中点的可视化锚点 |
| 受击红圈 | 红圆 10 px → 2.2 倍 220 ms | 替代角色变色（见下方坑 2） |
| 无敌闪烁 | alpha 0.45 / 90 ms 交替 | 明确告诉玩家"现在打不到你" |
| 死亡表现 | 淡出 + 拉长 + 上浮 240 ms | 清场反馈，不拖节奏 |

## 实测证据（无头 Chromium，2026-11-19）

| 用例 | 结果 |
|---|---|
| 闭环机器人走位接近最近怪 | 距离收敛到 22–38 px，未卡住 |
| 挥砍命中 | 怪 hp 6 → 3 → 0，`score` +1 |
| 连杀 | 一口气 4 只，score 0→4 |
| 被咬 | hp 20 → 17 → … → 0，`dead` 置真 |
| 死亡界面 | 遮罩 + "你倒了" + 重开提示正常显示 |
| 重开 | 点击后 hp 20 / score 0 / dead false |
| 控制台 | 无 `pageerror`，无音量/解码报错 |

## 三个坑

1. **Phaser WebAudio 无法解码 data URI 音频**：`decodeAudioData` 收到字符串，报 `parameter 1 is not of type 'ArrayBuffer'`。改成 `audio: { disableWebAudio: true }` 走 HTML5 Audio 后端，base64 mp3 直接可播。
2. **`setTintFill` 会把整块矩形涂满**：角色变色变成一个大红方块（截图确认）。改为 alpha 闪烁 + 几何图形火花，不依赖 tintFill。
3. **`SlashCurved` 的弧线质心不在贴图中心**（帧 1 质心在 0.68, 0.62）：绕贴图中心旋转会把特效甩到角色外面，看起来像脱手。改成以角色为圆心、贴图居中，弧线绕着角色扫。

## 未决与已知不足

- **攻击视觉与判定方向不完全一致**：弧线是绕身扫过，不是正前方 90°。判定本身在正前方，玩家可能觉得"看着砍侧面也中了"。`[待主测]`
- **音效只验证了解码不报错，没验证好不好听、音量合不合适**（无头环境听不到）。`[待你实测]`
- 没有难度曲线：现在是匀速刷怪，后期不会变难。
- 怪只会直线追，不会绕、不会攻击前摇。
- 地块仍是纯色，没有 Tiled 地图与地形阻挡。
