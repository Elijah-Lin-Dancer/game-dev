# 0002 主美术选定：Ninja Adventure

- 状态：已定稿
- 时间：2026-11-19
- 涉及段：1 调研 → 2 目标冻结（前置决策）
- 上游：[0001 素材来源与授权策略](0001-asset-sourcing.md)

## 背景

四套候选见 `docs/STYLE-PICK.md` 与 `docs/style-comparison/style-compare.png`。需要先锁一套主美术，才能确定颗粒度、色板与素材目录结构，避免后续换皮返工。

## 决策

主美术定为 **[Ninja Adventure](https://pixel-boy.itch.io/ninja-adventure-asset-pack)**（作者 Pixel-Boy / AAA，CC0）。

## 理由

1. **单包自洽**：50+ 角色、30+ 怪物、9 Boss、地块（含自动拼接）、UI、100+ 音效、37 曲、2 款字体、30+ 视觉特效，均在同一套色板与描边规则下。
2. **补齐两项最耗期的资源**：音效与字体是独立开发者最容易拖期的部分，这一包自带，且字体可直接用于中文以外的界面文本。
3. **CC0 无附加义务**：无需署名、无传染条款、可改作，适合后续长期迭代。
4. **16×16 适配移动端**：在 720p 逻辑分辨率下按 3 倍放大约 48 屏幕像素，角色与文字都可读，图集也压得住。

## 代价与缓解

| 代价 | 缓解方式 |
|---|---|
| 风格偏日式、暖橙，与冷色场景不搭 | 用 pixelfx 的 `palette` 参数把特效色板拉到同一色温，而非换美术 |
| 原始包约 89 MB | 只取实际用到的子集入库；原始全量包不入 git（见 `.gitignore`） |
| 缺写实向 / 高细节素材 | 接受。本项目为像素风，不追求写实 |

## 使用边界

- 只允许用一套补充素材，且**只补 UI 或特效，不补角色**。
- 不引入第三套美术；出现风格冲突时以 Ninja Adventure 为准。
- 素材入库必须连同包内 `LICENSE` 原文，登记到 `assets/CREDITS.md`。

## 备选与否掉理由

| 备选 | 否掉原因 |
|---|---|
| Tiny Swords | 64×64 素材重，移动端包体与内存需先实测；且**禁止再分发**，限制后续用法 |
| Kenney Tiny Dungeon | 氛围弱，不加光影几乎无表现力；虽最轻，但只能当骨架 |
| Pixel Adventure | 仅适合横版平台跳跃，玩法一旦不是横版即用不上 |

## 什么情况下改推荐

- 玩法确定为**横版平台跳跃**：改 Pixel Adventure（或保留 Ninja 做敌人/NPC，主场景换横版包）。
- 需要**同屏 10 单位以上**的战棋或塔防：改 Tiny Swords，并先做包体实测。
- 需要**中文像素字体**做主文本：保留 Ninja 的图形素材，文本层改用 Fusion Pixel（OFL），两者不冲突。
