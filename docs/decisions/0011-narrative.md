# ADR 0011 · 叙事层：NPC 对话、房间事件、周目继承

日期：2026-11-20
状态：已采纳

## 背景

打到 Boss 就结束了：没有一句话、没有一个 NPC、没有"为什么我还要再来一局"。数值上的跨局进度（累计金币/最深）是有的，但那只是统计，不构成动机。这一批做的是让地牢开始"说话"，并且给重复游玩一个由头。

## 决定

### 1. NPC 与对话（第一间必有引路人）

- 引路人在第一间固定出现（`Actor/Characters/Villager` 的 Walk 表第 0 帧），走近 56px 内出现 `E 交谈` 提示。
- 对话是底部对话框：说话人名（金色）、正文（逐字打字，28ms/字）、右下角 `E / 空格 继续`。
- 打字中点一次直接补全本行；已补全再点进入下一行；最后一行之后关闭并把控制权还给游戏。
- **对话期间世界暂停**：`update` 在 `talking` 时直接返回，敌人不动、不掉血、不能挥砍——避免读字时被打死。
- 文本全在 `web/data/story.json`，改文案不用重新构建；同一个人物第二次交谈走 `repeat` 短句。

### 2. 三类房间事件（每间确定性一次）

每个非 Boss 房间在第一次进入时掷一次骰子（45%），决定这一间有没有事件、是哪种；`room.eventKind` 记在房间上，回头再看还是同一个。

| 事件 | 外观 | 选项 | 设计意图 |
|---|---|---|---|
| 石龛 shrine | 青色石像 | 攻击 +1 / 移速 +1 / 攻速 +1 | 三选一，逼玩家本局定方向 |
| 行脚商 vendor | 村民 NPC | 回血 +6（3 金币）/ 强化 +1（6 金币）/ 离开 | 给局内金币一个出口 |
| 祭坛 curse | 红色石像 | 献祭 5 血换 +2 随机强化 / 离开 | 高风险高回报，血少时不敢碰 |

交互同样走 `E`：弹出居中面板（半透明遮罩 + 标题 + 说明 + 编号选项），可以点也可以按 1/2/3/4。石龛与祭坛用过变灰、不再触发；商人可以反复买。

### 3. 周目继承

- 存档 v3 新增 `cycle`（周目数，默认 1），通关一次 +1。
- 新一局开局按周目给起步强化：`power = min(3, (cycle-1) * legacyPower)`；HUD 显示 `第 N 周目`。
- 难度同步上涨：小怪血量 `× (1 + 0.15*(cycle-1))`，Boss 血量 `× (1 + 0.2*(cycle-1))`。这样周目不是"重复一遍"，而是"同一张脸更硬"。
- 三个系数都在 `balance.json` 的 `cycle` 组里，可调。

## 实测

| 项 | 结果 |
|---|---|
| 引路人对话 | 3 行依次打出，`E` 推进：行 1/3 → 2/3 → 3/3 → 关闭，无报错 |
| 对话暂停 | 对话期间敌人不动、不扣血（对话框截图中 HP 保持 20/20） |
| 石龛 | 面板 4 项；按 1 → `upg.power` 0→1，面板自动关闭 |
| 行脚商 | 10 金币买"强化 +1"（6 金币）→ 剩 4 金币、`upg.atk` +1；血 10 买回血 → 16 |
| 祭坛 | 血 20 → 15，随机两项强化各 +1（实测 speed/atk） |
| 周目 | 通关后存档 `wins:1, cycle:2`；刷新进第 2 周目：开局 `upg.power=1`，小怪血 6→7 |
| 存档迁移 | v2 档加载后补 `cycle:1`，旧数据不丢 |

## 修掉的坑

- 对话框与底部操作提示条重叠 → 对话时隐藏底栏、结束恢复。
- 事件面板选项排到框外（高度 150 装不下 4 项）→ 改为 190 高、选项从顶+96 起，并加全屏遮罩。

## 代价与边界

- 对话没有头像、没有分支、没有任务系统，是"展示型"而不是"选择型"；玩家只能按继续。
- 事件每局重掷，**不进存档**：玩家在 A 局见过的祭坛，B 局不一定在；也没有"事件图鉴"。
- 周目只放大血量，不加新招式/新怪/新事件；第 5 周目本质还是同一套牌更肉。
- 文本量很小（两个人、三个事件），叙事还没真正"长"起来。
