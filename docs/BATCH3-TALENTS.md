# 批 3 · 层间天赋（实施记录，2026-11-20）

## 1. 做了什么

每进 2 间房弹一次三选一，卡面有稀有度、名字、代价说明；选中的天赋**本局内**一直生效，与 `upg`（石龛/商店的线性小强化）分开计算。重开清零，不写存档。

- 数据：`web/data/talents.json`（14 张 / 3 档稀有度），构建期内嵌 + 运行期 `json` 覆盖，坏条目按白名单丢
- 系统：`src/systems/talents.js`（`normalizeTalents` / `rollTalents` / `mergeMods`）
- 场景：`play.js` 的 `offerTalent / showTalentPanel / pickTalent` + 数值口 `maxHp() / dmg() / atkCd() / moveSpeed()`
- 触发：`enterRoom()` 里 `roomsEntered % 2 === 0` 且非 Boss 房，延迟 240ms 弹卡（避开出生动画）

**素材：0 外部件、0 自绘**。卡面是 `Rectangle` + 现有 `NinjaPixel` 字体，没有引入新图。这符合 ADR 0013 的"动态 UI"例外，也符合你"能拿现成就不自己造"的要求——这里连现成件都不需要。

## 2. 天赋表

| 稀有度 | 张数 | 例子 |
|---|---|---|
| 普通 | 6 | 疾风（移速+15%/间隔+8%）、厚皮（上限+4/移速−8%）、贪婪（金币算2/上限−1）、快手、轻步、拾荒 |
| 稀有 | 5 | 狂战（攻+2/上限−3）、吸血、重击、铁胃（进房回1血/金币×0.5）、稳手（受伤×0.75/移速−10%） |
| 史诗 | 3 | 玻璃大炮（伤害×1.6/受伤×1.3）、孤注一掷、血契 |

抽卡权重 `common 60 / rare 30 / epic 10`，每深一间 `common −6 / rare +2 / epic +6`（下限 2）；同一局已选过的不再进池；三张全普通时强行换一张稀有以上（池里还有的话），并按稀有度排序（史诗放最左）。

## 3. 数值口径（关键）

```
maxHp   = CFG.maxHp + upg? + mods.maxHp                 // 只加 flat，下限 1
dmg     = round((CFG.playerDmg + powerStep*upg.power + mods.atk) * mods.dmgMul)
atkCd   = max(120, base(upg) * (1 + mods.atkCd))         // 正数=更慢
moveSpeed = 96 * max(0.4, 1 + speedStep*upg.speed + mods.speed)
受伤     = max(1, round(dmg * mods.takenMul))
金币     = 小数累加后取整（0.5 金币/枚不会因四舍五入变成 1）
```

flat 在乘区之前，`upg` 的线性加成也进 flat——这样"天赋倍率"和"小强化"不会互相放大成爆炸数值。

## 4. 验收（T 段）

| 编号 | 判据 | 结果 |
|---|---|---|
| T-1 | 每 2 间弹一次、3 张互不重复、Boss 房不弹 | 5 间局在 2/4 间各弹一次；6 间局弹 2 次；Boss 房无卡 |
| T-2 | 选"狂战"后上限 20→17、`dmg()` 3→5 | 实测 `maxHp 17 / dmg 5`，HUD 4 格半心同步 |
| T-3 | 同局不重复出现同一张 | 连续两次报价：`重击/贪婪/疾风` → `稳手/轻步/快手`，已选的不进池 |
| T-4 | 重开清零 | 重新载入后 `talents=[]`，`maxHp=20` |
| T-5 | 与 upg 分乘区，不互相污染 | 叠"重击 + 稳手"：`cd 300→360`、`speed 96→86`、`dmg 3→4`，`upg` 未变 |
| T-6 | 稀有度随深度上移 | 60 次抽卡：深度 1 = 91 普通/75 稀有/14 史诗；深度 5 = 73/58/49 |
| T-7 | 键盘 1–3 与鼠标点卡等价；选完立刻生效 | 按 `2` 选中"铁胃"，面板关闭，进下一间回血 +1 |
| T-8 | 全程可通关 | 5 间局带 2 个天赋打到 Boss，`won=true`，无 pageerror |

## 5. 已知取舍与风险

- **没有做"天赋图鉴/历史"**：存档只记 `roomsSeen`，天赋不写盘，符合"本局 Build"的定位。
- **代价型天赋可能出最优解**：目前 flat/乘区都压得比较小（最高 ×1.6 伤害换 ×1.3 受伤），观察到的极端组合是"玻璃大炮 + 重击"，DPS 约 ×2.16、受伤 ×1.3；如果实战里变成唯一解，就在 `talents.json` 调 `dmgMul` 或加"受伤 +"的代价。
- **卡面是纯 UI**，没有稀有度掉率动画；表现力留给批 6。
- **Boss 房不弹卡**：最终房前的那次天赋必须在第 4 间拿到，节奏上够用；如果以后想加"Boss 前必给一张"，把触发条件改成 `roomsEntered === roomTotal - 1` 即可。
