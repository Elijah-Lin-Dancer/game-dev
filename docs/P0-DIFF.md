# P0-2 逐章难度 · 交付

日期：2026-11-22
范围：《归途：星火之章》P0 UI/UX 改造第二刀。把原来的“全局普通/困难”改成“每章独立普通/噩梦/地狱”，入口挂在章节详情，进度写入存档。

## 1. 规则

| 项 | 当前实现 |
|---|---|
| 普通 | 始终可用；敌人血量 ×1.00、伤害 ×1.00 |
| 噩梦 | 本章普通全部关卡 ≥1 星后解锁；敌血 ×1.25、敌伤 ×1.20 |
| 地狱 | 本章噩梦全部关卡 ≥1 星后解锁；敌血 ×1.55、敌伤 ×1.40 |
| 选择粒度 | 按章保存：`save.diffSel[章 id] = normal / nightmare / hell` |
| 普通星级 | 写入 `save.stars["章:关"]`，参与关卡/章节解锁，也是主线进度的唯一来源 |
| 高难星级 | 写入 `save.tierStars["章:关"][tier]`，不覆盖普通星级，不影响主线解锁 |
| 章节未解锁 | 该章三档难度均不可进入；即使存档里有旧选择也会回落到普通 |
| 旧全局难度 | 旧 `na.options.difficulty = "hard"` 忽略，所有章默认普通；不自动迁移成噩梦 |

实现位置：

- `src/systems/difficulty.js`：三档定义、倍率、按章选择、解锁判断、高难星级读取、章内通关数。
- `src/systems/save.js`：存档 v7；新增 `diffSel`、`tierStars`，并做键名/取值清洗。
- `src/scenes/map.js`：章节面板右侧“难度”入口；三档覆盖层；锁定文案；选择后立即刷新本章节点星级。
- `src/scenes/select.js`：接收 `difficulty`，在准备进入文案里显示难度，并原样传给 Play。
- `src/scenes/play.js`：按 `data.difficulty` 取倍率，HUD 显示当前难度；结算时普通写 `stars`，高难写 `tierStars`。
- `src/scenes/title.js` / `src/systems/options.js`：设置面板只留“静音 / 震屏”，删除全局难度行与 `difficultyMods`。

## 2. 交互

1. 标题 → 开始冒险 → 世界地图。
2. 章节面板右下角显示“难度 普通 ›”；点击打开三档覆盖层。
3. 覆盖层显示本章普通通关进度（`n/章节关数`）、每档倍率、当前档、锁定原因。
4. 选档后覆盖层关闭；章节面板的星级统计切换到该档（例如“本章 噩梦 ★ 0/15”）。
5. 进入关卡 → 选人页标题显示“准备进入：竹林村 · 第 1 关 · 噩梦”。
6. 战斗 HUD 右上角显示“第 N 周目 · 噩梦”。
7. 通关结算标题追加“· 噩梦 / · 地狱”；高难星级单独入档。

键盘：`ESC` 关闭覆盖层，再按 `ESC` 返回标题；右键在覆盖层打开时只关层，不返回。点击遮罩同样只关层。

## 4. 待拍板 / 已知限制

| 项 | 现状 | 影响 |
|---|---|---|
| “本章普通通关”定义 | 当前按“全关 ≥1 星” | 若只想按章末 Boss 1 星，会明显降低噩梦门槛 |
| 旧全局困难迁移 | 当前忽略，全部普通 | 老玩家需要重新在每章选难度 |
| 高难奖励 | 当前只单独记星，不额外给金币/宝石 | 高难目前是挑战与记录，不是经济收益路径 |
| 高难是否影响章节解锁 | 当前不影响，下一章仍要求普通星级 | 避免高难卡关导致主线死锁 |
| 难度入口位置 | 暂放章节面板，不另开“关卡详情”页 | P1 若拆独立详情页，可把入口迁过去 |
| 高难星级展示 | 地图节点显示当前档星级；顶部主线统计仍只统计普通 | 玩家可切换档位查看，不混淆主线进度 |
| 线上 Pages | 2026-11-22 已推送 `7a19bad`，Pages 构建完成 | 线上入口已切到 `game.f9577523.js`；在线标题/地图实测通过，单文件版 HTTP 200 |
