# P1 上手自测清单

这轮只能由你来判断：**手感成不成立**。自动化能验的（判定、掉血、死亡、重开）都已经验过了，验不了的是"爽不爽"。

玩之前先做一件事：**戴上耳机**，音效这轮刚接进来，我这边听不到。

## 五分钟流程

1. 打开 `web/game.html`，先不动，看 3 秒——怪会朝你走过来。
2. 砍第一只怪。**两刀**应该死。
3. 故意挨一下咬，看心掉多少。
4. 连续砍 4 只，看有没有"想再砍一只"的冲动。
5. 站着不动，被咬到死，点一下屏幕重开。

## 六个问题（凭直觉答，不要分析）

| # | 问题 | 通过的样子 |
|---|---|---|
| 1 | 按下去到弧光出现，有没有延迟感？ | 没有。若有，是输入没跟手 |
| 2 | 砍中的瞬间，有没有"顿一下"的感觉？ | 有，像打在实物上。没有 → 命中冻结要加长 |
| 3 | 砍空的代价够不够？ | 有轻微迟滞但不烦。太黏 → 冷却要减 |
| 4 | 被咬的时候，知不知道自己被咬了？ | 一眼看出来（红圈 + 震屏） |
| 5 | 怪的压迫感够不够？ | 会紧张但不窒息。太松 → 加速度；太紧 → 减同屏数 |
| 6 | 还想再砍一只吗？ | 想 → 核心动词成立，可以进 P2 |

## 直接告诉我这些数字就行

- 打击感：**太轻 / 刚好 / 太重**
- 挥砍节奏：**太慢 / 刚好 / 太快**
- 怪的压力：**太松 / 刚好 / 太紧**
- 音效：**听得到 / 听不到 / 太吵**（听不到大概率是浏览器拦了自动播放，点一下屏幕就好）

有更细的感受也直接说，比如"砍空时人物滑太远""弧光出现在身后"，这些我按你说的调。

## 不在这一轮范围内的

- 关卡、地图、房间结构（P2）
- 更多怪种、Boss（P2）
- 对话、据点、解锁（P3）
- 手机端的实际手感（这台机器只能模拟触屏，真实跟手度要你拿手机试）
