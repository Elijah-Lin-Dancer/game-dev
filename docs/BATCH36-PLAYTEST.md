## 真实游戏修复

1. **敌人可生成在墙后夹层**：`findFreeSpot()` 只查 `isWall`，不查与玩家连通性；第 1 关实测 `eye` 刷在底部墙后，近战永远够不到、房间无法清场。已加入 `reachableTiles()` BFS，只选与玩家连通且不压墙的格子。
2. **第一章敌人密度过高**：原 `3–5 + min(2, idx)`，单房可到 6–7 只。现第一章五关统一封顶 3 只；Boss 血量仍随关深缩放，难度留在 Boss 与操作上。
3. **篝火经济断档**：多次到篝火 0–1 金币，付不起 2 金币回血。每次战斗房清场一次性掉 1 枚保底金币（`room.clearCoin`），叠在 45% 随机金币上；本轮第 1、3 关均实际付费回血 6。
4. **巨浣熊跃扑不可走位躲避**：原 `pounceRadius 74 / windup 440ms`，玩家 96 速只能移动 42px，落点圈锁在脚下，走路必吃；抓击 `reach 64 / 300ms` 同理。已改为 `pounce 48 / 680ms`、`swipe 52 / 400ms`。第 4 关由三连灭变为首试通过。

## 实机机器人修复

`tools/playtest_ch1.mjs` 本轮修掉两个会污染结论的机器人缺陷：

- **贴脸软锁**：原来 `dist < 36` 先后退，墙角被堵时永远退不出去，第 2 关首房实机复现 110s 超时。改为“先砍再退”，攻击冷却中才退半步；这一条直接消掉超时。
- **Boss 只等 recover 打不到**：青蛙 `recover` 仅 380ms，从 100 距离赶不上刀。改为非危险相位贴到 46 内持续攻击，前摇/冲撞由 `phase / ring` 分支立即接管躲避；Boss 前摇低血交 Q 吃无敌帧。
- 其他：按真实可走路径选目标、天赋按生存权重选卡（厚皮/稳手/铁胃优先，血契/孤注一掷/玻璃大炮降权）、眼怪弹道预测 0.8s / 42px、独眼蓄力横向侧移、掉落先捡金币/心/强化/钥匙、只走 `targetIdx > 当前 idx` 的门。
