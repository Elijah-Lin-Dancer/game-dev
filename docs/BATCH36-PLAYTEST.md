## 真实游戏修复

1. **敌人可生成在墙后夹层**：`findFreeSpot()` 只查 `isWall`，不查与玩家连通性；第 1 关实测 `eye` 刷在底部墙后，近战永远够不到、房间无法清场。已加入 `reachableTiles()` BFS，只选与玩家连通且不压墙的格子。
2. **第一章敌人密度过高**：原 `3–5 + min(2, idx)`，单房可到 6–7 只。现改为 1–2 关封顶 3 只、3–5 关封顶 4 只。
3. **篝火经济断档**：多次到篝火 0–1 金币，付不起 2 金币回血。每次战斗房清场一次性掉 1 枚保底金币（`room.clearCoin`），叠在 45% 随机金币上。
4. **巨浣熊跃扑不可走位躲避**：原 `pounceRadius 74 / windup 440ms`，玩家 96 速只能移动 42px，落点圈锁在脚下，走路必吃；抓击 `reach 64 / 300ms` 同理。已改为 `pounce 48 / 680ms`、`swipe 52 / 400ms`。第 4 关首试由 3 连灭变为一次通过。

## 实机机器人

`tools/playtest_ch1.mjs`，只使用真实键盘 `WASD / Space / E / Q / 1-3 / Enter / Escape / ArrowDown`，不调用 `__dbg.next()` / `__dbg.win()`。

- 启动：连续两次 `map.activate()` 后进入 Select。
- 过门：读 `nextDoors`，只走 `targetIdx > 当前 idx` 的门。
- 移动：BFS 格心对齐，避免贴墙角顶墙。
- 战斗：hit-and-run；按可走路径选目标；独眼/蜥蜴蓄力横向侧移；低血 Q 疾影冲刺。
- Boss：读 `phase / ring`，前摇与冲撞躲避，硬直 `recover` 反击；Boss 前摇低血交 Q。
- 天赋：按生存权重选卡（厚皮/稳手/铁胃优先，血契/孤注一掷/玻璃大炮降权），避免机器人盲选把 20 血压到 12–16。
- 掉落：只捡金币/心/强化/钥匙，暂跳过武器互换。
- 篝火：面板第一项含“回”且金币≥2 时按 1 付费回血。
- 失败：同关最多 3 次，3 次全灭即中止后续关并写 `passed:false`。
