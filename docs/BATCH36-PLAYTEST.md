## 本轮真实缺陷修复

1. **远程怪隔墙放弹幕**：蜘蛛 / 骷髅 / 眼怪只按距离判断，不看墙体；实机多次出现玩家在墙后、怪在另一侧持续射击，近战够不到。`enemyShot()` 现在先走 `lineOfSight()` 采样，墙后不开火。
2. **远程怪刷进 1 格死角**：`findFreeSpot()` 只查连通，不查开阔度；远程怪会卡在墙角一侧，玩家绕不过去也砍不到。现在远程怪要求至少 3 个开放邻格，普通怪至少 2 个。
3. **Boss 掉落来不及拾取**：Boss 死后 0.9s 直接结算，结算后拾取循环被 `won` 停掉。现在窗口放宽到 1.2s，并在 `win()` 前自动收走剩余金币 / 心 / 强化 / 钥匙，避免远程击杀丢奖励。
4. **旧堡首章密度与补给断档**（为第二章试点先修的）：旧堡小怪统一封顶 3 只；第 1 关首间只放 2 只并只教分裂 / 钻地；房间模板加入篝火；幼虫 / 史莱姆 / 鼹鼠伤害 3→2。

## 机器人修复

- 贴脸先砍再退，消掉墙角 110s 软锁。
- Boss 非危险相位主动贴脸攻击，不再只等 `recover`。
- 风筝怪（蜘蛛 / 骷髅 / 眼怪）近身后持续贴住，不再打一刀就退。
- 自动换到苦无 / 魔杖 / 短弓时改用远程攻击逻辑；旧堡机关房曾因此贴到碰撞距离后永远不出手。
- 机关房清场后走到石像按 E 拉机关。
- 天赋按生存权重选卡；眼怪弹道预测 0.8s / 42px；低血 Q 脱离包围。
