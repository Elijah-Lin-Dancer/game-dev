# P1-C-4：Play HUD 与浮层迁移

状态：已完成并推送 `a7a9b6c`（代码 / 构建）、`2313208`（文档 / 截图）；Pages 已切到 `dist/game.86f15d99.js`，线上 Play HUD / 暂停 / 死亡结算实测通过，`errs=[]`。Play HUD、暂停、死亡 / 通关结算、事件、商店、篝火、天赋、引路人对话已迁入 `tokens / primitives`，960×540 / 640×360、实际入口、单文件冒烟均通过。

## 范围

- Play HUD：房间信息、提示条、技能冷却、强化、周目 / 金币 / 最深、限时、武器名、交互提示、房名横幅。
- Play 浮层：暂停、死亡 / 通关结算、事件（石龛 / 祭坛 / 行商）、商店、篝火、天赋三选一、引路人对话。
- 只做视觉 / 布局 / 组件迁移，不新增玩法，不改数值，不改关卡与场景导航；保留键盘、触控、暂停、结算、面板关闭与恢复行为。

## 实现

### HUD 文本

- `tokens.js` 新增 `UI.hud`：`bg '#0a0f12dd'`、`bgSoft '#0a0f1299'`、`bgClear '#0a0f1266'`，替代 Play 内散落的黑底透明度。
- 新增 `hudText()`：统一 `makeText` + 滚动锁定 + 深度 + HUD 背景；新增 `screenPanel()` 锁定浮层面板滚动；新增 `destroyPanelRow()` 兼容卡片行与普通对象销毁。
- `buildHud()` 全部改为 `hudText`：`info / hint / skillText / upgText / metaText / timerText / weaponName / promptT`。
- `timerText` 从 14px 收到 12px；限时 ≤30 秒仍用 `UI.text.danger`。
- `roomBanner()` 改为 `h1` 24px，Boss 房用 `UI.text.danger`，普通房用 `UI.text.heading`。
- `floatText()` 改为 `makeText(..., 'body')` + `UI.hud.bgSoft`，保留世界坐标、深度 640 与上浮动画。
- `weaponIcon` 保留 2× 整数缩放；心形 / 小地图 / Boss 血条仍是既有图形绘制，本次未改。

### 浮层

- `talk()` 引路人对话：`screenPanel` 底条 + `hudText` 姓名 / 正文 / 继续提示；打字机、`E / 空格` 补全与关闭逻辑不变。
- `showPanel()` 事件 / 商店 / 篝火：统一 400×168 起的 `screenPanel` + 行卡 `makeCard`；行文字 12px，编号 / 离开 / 禁用态保留。`panel.rows` 改为 `{ card, label }`，关闭时兼容销毁。
- `showTalentPanel()` 天赋三选一：面板 + 3 张 108×116 卡片；名字、稀有度、代价说明、编号保留；点击卡或 1–3 选择不变。
- `togglePause()` 暂停：320×176 面板 + 2 张行卡（继续 / 回小屋）+ 底部提示；ESC / Enter 继续、H 回小屋保留。
- `showOverlay()` 死亡 / 通关结算：460×150 面板 + 24px 标题 + 12px 正文 / 提示；点击或 R / Enter 的重开 / 回地图行为保留。
- **ESC 修正**：事件 / 商店 / 篝火面板打开时 ESC 先关面板，不再把暂停叠在面板上；天赋必须选一张，不响应 ESC。

## 视觉门禁

- Play 内文本只来自 `UI.size`：`h1=24`、`h2/body/caption=12`；`play.js` 已无 `FONT`、`fontFamily`、直接 `fontSize` 写法。
- 960×540 / 640×360：HUD 顶栏、右上进度、底部提示、武器行不重叠不裁切；暂停、死亡结算、对话、事件、商店、篝火、天赋、限时计时均生成双尺寸截图。
- 640×360 下 `hint` 仍通过 `fitHint()` 自适应缩放；事件 / 商店行卡文字不溢出；天赋三卡代价说明在 640 下仍在卡内。
- 键盘：WASD / 空格 / Q / E / M 保留；事件 / 商店 / 篝火 1–4、ESC 关闭；天赋 1–3；暂停 ESC / Enter / H；结算点击 / R / Enter。
- 触控：暂停「继续游戏」卡、事件行、天赋卡、结算中心点击均已实际点击验证；对话 E / 空格推进验证。
